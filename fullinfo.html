Infra Intel

Security Intelligence Platform — Security Audience Overview

A unified platform for correlating AWS, Palo Alto, Wiz and other security data into a searchable investigation and automation capability.

01 / 10

What is Infra Intel?

A single security intelligence layer across fragmented infrastructure data.
"Turn disconnected infrastructure and security data into one searchable, correlated investigation platform."

AWS

Accounts, VPCs, CIDRs, EC2, ENIs, Security Groups, DNS and cloud resources.

Palo Alto

Objects, groups, services, applications, policies, NAT/PBF and rule relationships.

Wiz

Findings, policies, controls, cloud resources and security group relationships.

02 / 10

The Security Data Problem

Investigations often require jumping between multiple systems.
Fragmented data AWS, firewall, vulnerability and DNS information live in separate platforms.
Manual correlation Analysts have to manually connect IPs, hosts, security groups, firewall objects and findings.
Slow investigations Simple questions can require multiple consoles, APIs and spreadsheets.
Collector dependency Data pipelines often become tightly coupled to the applications consuming them.
The problem is not lack of data.
The problem is connecting the data.

Search & Policy Capabilities

Investigation starts with the question the analyst actually has.

Search & Investigate

IP / CIDR, EC2 instance ID, ENI, Security Group, DNS/R53, Palo Alto objects and rules.

Firewall Policy Lookup

Source, destination, port, source-only or destination-only queries with allowed/denied policy results.

Palo Alto Object Search

Address objects, address groups, services, applications, service groups and custom URL categories.

CIDR Rollup

A /32 can be placed into its subnet, VPC or larger relevant CIDR context for investigation.

Search results should show the useful security relationships first, with raw/noisy source data available when needed.

Why this layer is decoupled

Collector independence

A collector can be written in Python, Lambda, Step Functions, CI/CD, a vendor platform or another approved technology.

Application independence

The application does not need collector-specific code merely because another security source was added.

Adding a New Collector

New Security Tool │ ▼ Generate standard event JSON │ ▼ Write JSON to S3 │ ▼ S3 ObjectCreated │ ▼ Existing ingestion pipeline │ ▼ Existing database/search │ ▼ Existing Infra Intel application
No application rewrite required. The new collector only needs to implement the agreed event contract and publish its output to the correct S3 location.
